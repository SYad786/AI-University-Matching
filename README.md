# AI University & Supervisor Matching

**Author:** Syad Ali Raza  
**Hackathon Event:** Hack-Nation AI Challenge  

## Description
AI-powered system that recommends the best-fit universities and research supervisors for international students using semantic similarity and fine-tuned language models.

## Features
- Matches student research interests with universities and supervisors
- Uses a pre-trained Sentence Transformer model for semantic similarity
- Provides a ranked list of recommended universities
- Easy to extend with more universities and supervisors
